Morrow 1.0.0 is a complete rebuild of Finance Tracker.

- Dark Android-first interface, custom identity, responsive desktop layout, spring navigation and animated balances.
- Earnings enter Savings; funded category budgets enforce spending limits. Recurring template revisions preserve previous months.
- Immutable corrections, refunds, archive/reopen, local SQLite on Android and IndexedDB in browsers.
- Preserved legacy history, migration receipts, complete readable recovery files, editable imports, Excel formulas, and safe GitHub backup.

Install the attached Morrow-1.0.0.apk. For existing data, open the browser app at the original Finance Tracker address, export My space → Complete JSON, and restore that file in Morrow on Android. Existing browser records are preserved during migration.

This release uses a dedicated persistent signing key. Keep external recovery copies of your financial records.
